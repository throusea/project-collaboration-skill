# Project Collaboration Skill

**让 AI 在长期项目中，逐渐理解你、跟上你的节奏，并与你一起推进工作。**

你有没有遇到过这些情况？和 AI 讨论了很久的约定，下次又要重新解释；你只是想讨论一个想法，它却开始替你做决定；你想自己动手学习，它又直接给出了完整答案。

Project Collaboration Skill 为每个项目建立一个轻量的协作机制：让 AI 根据当前对话判断你是在**一起推进工作、平等讨论，还是学习知识**；把值得保留的共同理解记录下来；在后续任务中，根据目标和已有共识判断如何分工。

## 它能帮你做什么？

**让讨论过的事情延续下去。** 项目共识库记录双方认可的术语、沟通偏好和关键理解。以后遇到相关问题，助手可以先读取并沿用，不必让你反复解释。

**让助手识别你现在需要什么。** 你提出观点时，助手与你讨论；你委托任务时，助手主动推进并提供判断；你想学习时，助手帮助你组织知识、实践和反馈。交流过程中可以随时切换。

**让分工服务于你的目标。** 助手结合你的目标、已有能力和可用资源，判断哪些事情值得你亲自练习，哪些只需了解或验收，哪些可以由助手完成或复用已有成果。你始终可以调整分工。

**让学习进度看得见。** 对持续学习的主题，学习地图记录当前目标、已经验证的理解和下一步，让你休息或换窗口后更容易接上。

### 一个例子

假设你正在学习游戏客户端开发，想实现一个拾取动作：

> 你：我想自己理解角色状态和动画之间怎么配合，但不想花太多时间准备测试素材。
>
> 助手：我们可以由你动手实现拾取状态和动画通知；我负责整理测试素材、查节点用法，并陪你分析运行结果。
>
> 你：动作结束后角色还是不能移动，我觉得可能是状态没有清掉。
>
> 助手：我们先检查动画完成和中断时，是否都恢复了控制；这个问题值得你亲自调试，因为它关系到后面类似交互的判断。

这是一个示意场景。协作约定和学习记录会随实际交流逐步形成，助手需要根据当前问题重新判断，而不是机械套用固定角色。

## 开始使用

在你的项目中，把下面这段话发给能够读取仓库并操作项目文件的 AI 助手：

```text
请读取 https://github.com/throusea/project-collaboration-skill/blob/main/skills/project-collaboration-setup/SKILL.md ，按这个 Skill 为当前项目初始化协作机制。
```

助手会按初始化 Skill 获取所需文件、检查项目已有配置，并建立协作入口。初始化后，可以直接开始讨论、交代任务或学习；你也可以在交流中告诉助手哪些理解需要修正。

如果使用 Codex 的 skill-installer，也可以安装本仓库的 `skills/project-collaboration-setup`，再说“为当前项目初始化协作机制”。客户端的文件和网络访问仍遵循自身权限设置。

## 它在项目里留下什么？

| 内容 | 作用 |
| --- | --- |
| `AGENTS.md` 协作入口 | 提醒助手识别语境、读取项目共识并按需选择 Skill |
| `docs/ContextAndIntent.md` | 描述如何识别合作、讨论、学习和理解反馈等语义 |
| `docs/CollaborationConsensus.md` | 保存本项目逐步形成的共同理解，初始化时为空 |
| `.agents/skills/shared-understanding/` | 维护和使用共识，并根据目标判断合作分工 |
| `.agents/skills/adaptive-teaching/` | 组织解释、实践、反馈和学习节奏 |
| `docs/learning/` | 持续学习时按需创建主题记录 |

共识只记录对后续协作有用的信息，不需要保存每轮对话。具体任务的分工留在任务记录中；不同项目的共识默认各自独立。

## 已有项目可以使用吗？

可以。初始化会保留已有内容；重复运行不会重复追加相同入口。如果同名 Skill、语境文档或已管理入口的内容不同，安装会停止并提示合并，不会直接覆盖。安装记录会保存来源提交和 Skill 指纹，已有项目不会自动追随远端升级。

每个项目的目标和协作方式不同，初始化后的模板可以按需调整。仓库中的 `examples/` 供参考，不会自动安装；公开模板不包含原项目的研究记录或个人绝对路径。

## 手动安装与验证

需要 Git 和 Python 3：

```sh
git clone https://github.com/throusea/project-collaboration-skill.git
python project-collaboration-skill/scripts/setup.py --project /absolute/path/to/project
```

可使用 `--consensus notes/consensus.md --learning notes/learning` 自定义项目内的共识库和学习记录路径。

运行仓库自带的安装测试：

```sh
python -m unittest discover -s project-collaboration-skill/tests
```

安装测试检查文件保护与重复运行；协作效果还需要在真实对话中观察和调整。
