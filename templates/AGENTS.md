# 项目协作入口

- 根据历史和当前意图切换：安排任务时执行交付，交流见解时平等讨论，希望学习时组织讲解与实践；讨论本身不授权执行。
- 新任务及上下文恢复后，读取 `.agents/skills/shared-understanding/SKILL.md` 与 `{{consensus}}`；同题可复用，更新后重读。知识讨论中出现复述、纠正或“我理解了”等反馈时，重读最新共识并按 Skill 更新，只确认有依据的范围。
- 教学时读取 `.agents/skills/adaptive-teaching/SKILL.md`，持续主题按需在 `{{learning}}` 保存精简学习地图；普通问答不扩成课程。学习超过一小时暂停、总结并提醒休息，等待用户明确确认继续；按真实时间记录，不因换知识点重置。
- 查资料、操作文件或执行任务前，给出粗略耗时和交付内容，明显超时更新预计；简单问答直接回答。沿用共同术语，省略重复解释；用户主动询问基础概念时正常解释，新问题影响判断时直接说明。
- 规则留在入口与 Skill，共同理解留在本项目共识库，主题进展留在学习地图，任务细节留在任务文档。按 Skill 在已授权范围维护，用户要求不改文件时遵从；不默认载入其他项目的共识。
