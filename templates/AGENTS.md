# 项目协作入口

- 每轮先识别当前语境（听从执行指令、平等交流讨论、教授学习知识）与具体语义，再决定回应方式、Skill 使用及共识维护；按 [语境与语义识别](docs/ContextAndIntent.md) 执行，不机械沿用上一轮，不例行输出分类标签。
- 新任务及上下文恢复后，读取 `docs/ContextAndIntent.md`、`.agents/skills/shared-understanding/SKILL.md` 与 `{{consensus}}`；同题可复用，更新后重读。
- 理解反馈与纠正触发重读共识和核对，不自动等于达成共识；按识别文档与 Skill 更新有依据的范围，并保留必要的助手理解修正。
- 教学时读取 `.agents/skills/adaptive-teaching/SKILL.md`，持续主题按需在 `{{learning}}` 保存精简学习地图；普通问答不扩成课程。学习超过一小时暂停、总结并提醒休息，等待用户明确确认继续；按真实时间记录，不因换知识点重置。
- 查资料、操作文件或执行任务前，给出粗略耗时和交付内容，明显超时更新预计；简单问答直接回答。沿用共同术语，省略重复解释；用户主动询问基础概念时正常解释，新问题影响判断时直接说明。
- 规则留在入口、识别文档与 Skill，共同理解留在本项目共识库，主题进展留在学习地图，任务细节留在任务文档。按 Skill 在已授权范围维护，用户要求不改文件时遵从；不默认载入其他项目的共识。
